# 결산서 전수(全數) 정합성 점검기

지방자치단체 결산서의 **모든 숫자를 빠짐없이 기계 검산**하는 웹 도구입니다.
사람·LLM이 크로스체킹을 하면 겉핥기로 샘플링하기 쉽지만, 코드 엔진은 모든 행을
순회하므로 구조적으로 건너뛸 수 없습니다 — 그것이 이 도구의 존재 이유입니다.

🌐 https://castor428.github.io/balance-checker/

- **"의견" 도구가 아닙니다.** 감사 의견·심각도 등급을 매기지 않고, "이 값과 저 값이 안 맞음 → 확인 필요" 식의 담백한 검산 실패 목록만 제시합니다.
- **파일은 브라우저 안에서만 처리됩니다.** 업로드한 파일이 외부 서버로 전송되지 않습니다.
- 검산 실패 항목은 확인이 필요한 **"후보"**입니다. 표의 정의 차이로 인한 정상적 차이일 수도 있으므로 최종 판단은 회계 담당자가 합니다.

## 사용법

1. `index.html`을 웹브라우저로 엽니다 (배포된 경우 위 URL 접속).
2. 결산서 xlsx 파일을 끌어다 놓거나 클릭하여 선택합니다.
   - **「2. 결산서」와 「5. 세입세출결산서 첨부서류」를 함께 올리면** 양쪽을 모두 전수 검산합니다.
   - 한 개만 올려도 그 파일로 가능한 검증은 수행됩니다.
   - e-호조(지방재정관리시스템)에서 내려받은 원본 xlsx를 그대로 쓰면 됩니다.
3. 상단에 **전수 커버리지(증명)**, 그 아래 **검산 실패 목록**과 **검증 불가(육안 확인) 목록**이 표시됩니다. `CSV로 내려받기`로 저장할 수 있습니다.

## 전수 검산 — 5종 패스

숫자 하나는 떼어놓고 검증할 수 없습니다. 검증이란 "그 숫자가 들어가는 관계식이 성립하는가"입니다.
결산서 양식에는 검증 가능한 관계가 5종 있고, 엔진은 이를 **모든 시트·모든 행에 빠짐없이** 적용합니다.

| 패스 | 내용 |
|------|------|
| ① 행내 산식 | 헤더에 명시된 등식(㉰=㉮+㉯, ④=①+②-③ 등)을 모든 데이터 행에서 검산 |
| ② 합계행 검산 | 모든 표의 "계"·"합계" 행 = 데이터 행 합산 |
| ③ 계층 소계 | 장>관, 분야>부문 등 상위 과목 = 직속 하위 과목 합 |
| ④ 표 간 교차 | 같은 값이 여러 표/파일에 나오면 일치 검증 (별표8↔14-2, 별표12-1↔12-2, 세출 부문별↔목별↔구조별 등) |
| ⑤ 구조 무결성 | 연도 행 누락·중복 등재, 진도율 산출근거 등 |

어느 패스에도 안 걸린 숫자 셀은 **"검증 불가 — 육안 확인 필요"** 목록으로 분리해
화면·CSV에 그대로 노출합니다. 이것이 "겉핥기하지 않았다"는 증명입니다.

## 점검 대상 시트

**「5. 첨부서류」** — 별표 8(주요사업 추진현황), 12-1·12-2(계속비결산명세서), 14-2(이월사유별현황·계속비)

**「2. 결산서」** — 세입결산총괄, 세출결산총괄, 세입(관별), 세출(부문별·목별·구조별)

> 후속 과제: 세입(목별)은 부서별 반복 헤더 구조라 계층 파싱 전용 보강 후 추가 예정.
> 기금 결산, 「3. 재무제표」도 엑셀 원본 입수 후 같은 방식으로 추가 가능.

## 배포

별도 서버가 필요 없는 **정적 웹앱**입니다. 폴더 전체를 정적 호스팅에 올리면 됩니다.
빌드 과정 없음 — 파일을 그대로 올리면 동작. SheetJS(`lib/xlsx.full.min.js`)를 로컬 동봉해
외부 CDN 차단 환경에서도 동작합니다.

로컬 확인:
```
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

## 유지보수 — 결산서 서식이 바뀌면

서식이 개정되어 시트명·열 순서가 바뀌면 두 곳만 수정하면 됩니다:
- `js/constants.js` — 시트명 매칭, 열 위치, 시트별 검산 스펙(산식·계층)
- `js/settlement-parsers.js` — 「2. 결산서」 시트별 열 위치(`SETTLE_SHEETS`)

수정 후 회귀 테스트 (Node.js 필요):
```
node selftest.mjs "<첨부서류 xlsx>" "<결산서 xlsx>"
```
파서 인식 결과, 커버리지, 5종 패스 검산 결과가 콘솔에 출력됩니다.
인식 행 수가 0이거나 비정상적으로 적으면 위 두 파일의 시트명·열 위치를 점검하세요.

## 파일 구성

```
index.html               업로드 화면
css/style.css
js/
  app.js                 다중 파일 업로드 UI·파이프라인 연결
  constants.js           시트명·열 위치·검산 스펙  ← 서식 변경 시 수정
  parsers.js             「5. 첨부서류」 별표 파서
  settlement-parsers.js  「2. 결산서」 시트 파서   ← 서식 변경 시 수정
  matching.js            사업명 정규화·매칭
  engine.js              전수 검증 엔진 (5종 패스 + 커버리지 추적)
  report.js              결과 화면 렌더·CSV 내보내기
lib/xlsx.full.min.js     SheetJS (xlsx 파싱, 로컬 동봉)
selftest.mjs             회귀 테스트 스크립트 (Node.js)
```
