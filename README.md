# 결산서 정합성 점검기

지방자치단체 결산서 부속서류(별표 8·12·14) 간의 **수치·구조 오류를 자동으로 점검**하는 웹 도구입니다.
회계 담당자가 결산서 작성 단계에서 스스로 자가점검하는 용도로 만들었습니다.

- **"의견" 도구가 아닙니다.** 감사 의견·심각도 등급을 매기지 않고, "이 값과 저 값이 안 맞음 → 확인 필요" 식의 담백한 오류 목록만 제시합니다.
- **파일은 브라우저 안에서만 처리됩니다.** 업로드한 결산서 파일이 외부 서버로 전송되지 않습니다.
- 점검 결과는 확인이 필요한 **"후보"**입니다. 표의 정의 차이로 인한 정상적 차이일 수도 있으므로, 최종 판단은 회계 담당자가 합니다.

## 사용법

1. `index.html`을 웹브라우저로 엽니다 (배포된 경우 해당 URL 접속).
2. 결산서 **「5. 세입세출결산서 첨부서류」 xlsx 파일**을 끌어다 놓거나 클릭하여 선택합니다.
   - 별표 8·12-1·12-2·14-2가 모두 이 한 파일 안에 시트로 들어 있습니다.
   - e-호조(지방재정관리시스템)에서 내려받은 원본 xlsx를 그대로 쓰면 됩니다.
3. 점검 결과가 규칙별 표로 표시됩니다. `CSV로 내려받기`로 결과를 저장할 수 있습니다.

## 점검 항목 (9종)

| ID | 점검 내용 |
|----|-----------|
| C1 | 별표8 ↔ 별표14-2 **총사업비** 대조 |
| C2 | 별표8 ↔ 별표14-2 **사업기간**(시작·종료일) 대조 |
| C3 | 별표12-1 총괄 ↔ 별표12-2 사업별(당해연도) 금액 대조 |
| C4 | 별표12-2 **연도 행 누락·중복 등재** 검출 |
| C5 | 별표12-2 **이월액 연결** 검증 (n년 다음연도이월액 = (n+1)년 전년도이월사업비) |
| C6 | 별표8 **진도율 산식** 검증 (기투자÷총사업비 등으로 설명되는지) |
| C7 | 각 별표 **합계행 검산** (계·합계 행 = 데이터 행 합산) |
| C8 | **사업명 누락 교차검증** (별표12-1·12-2·14-2 모두에 등재됐는지) |
| C9 | **오타 패턴 의심** (총사업비가 정확히 10·100배 차이 → 자릿수 입력 오류) |

## 배포

별도 서버가 필요 없는 **정적 웹앱**입니다. `webapp/` 폴더 전체를 정적 호스팅에 올리면 됩니다.

- GitHub Pages, Netlify, 또는 시청 내부망 웹서버 등 어디든 가능
- 빌드 과정 없음 — 파일을 그대로 올리면 동작
- SheetJS(`lib/xlsx.full.min.js`)를 로컬 동봉했으므로 외부 CDN 차단 환경에서도 동작

로컬에서 바로 확인하려면:

```
cd webapp
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

## 유지보수 — 결산서 서식이 바뀌면

결산서 서식이 개정되어 **시트명이나 열 순서가 바뀌면 `js/constants.js` 한 파일만 수정**하면 됩니다.
시트명은 부분일치(정규식)로 찾으므로 앞 번호·공백 표기 차이는 자동 흡수됩니다.

수정 후에는 회귀 테스트로 동작을 확인하세요 (Node.js 필요):

```
node selftest.mjs "<결산서 5.첨부서류 xlsx 경로>"
```

파서 결과 요약과 9종 점검 결과가 콘솔에 출력됩니다. 별표별 인식 행 수가 0이거나
비정상적으로 적으면 `constants.js`의 시트명·열 위치를 점검하세요.

## 파일 구성

```
webapp/
  index.html          업로드 화면
  css/style.css
  js/
    app.js            UI 제어·전체 파이프라인 연결
    constants.js      시트명·열 위치 매핑  ← 서식 변경 시 여기만 수정
    parsers.js        별표별 xlsx 파서
    matching.js       사업명 정규화·매칭
    checks.js         점검 규칙 9종
    report.js         결과 화면 렌더·CSV 내보내기
  lib/xlsx.full.min.js  SheetJS (xlsx 파싱 라이브러리, 로컬 동봉)
  selftest.mjs        회귀 테스트 스크립트 (Node.js)
```

## 적용 범위

- 현재 버전은 **일반회계 계속비 사업** 중심으로 점검합니다 (별표 8·12·14의 핵심 대조).
- 표 내부 자유텍스트 대조(예: 별표8 사업내용란·비고란의 면적 표기 불일치)는 포함되지 않습니다.
- 검증 기준: 지방자치단체 2025회계연도 「5. 세입세출결산서 첨부서류」(e-호조 표준 서식).
  서식이 같으면 다른 지자체 결산서도 동일하게 동작하나, 서식이 다르면 `constants.js` 조정이 필요할 수 있습니다.
